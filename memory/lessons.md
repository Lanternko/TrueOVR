# 經驗教訓（lessons）

做事方法、建模、流程與量測方法的教訓。每個被抓到的錯誤寫一筆；能自動檢查的就加測試。讀寫規則見 [README.md](README.md)。

2026-10-30 依使用者要求整併：同主題的教訓合成一條（保留該主題的代表 ID），每件事故縮成「由來」一行。舊 ID 去哪裡，見檔尾「舊 ID 對照」；其他檔引用舊 ID 時查那張表。

整併至：L-114（2026-11-02；L-104 從未存在）。

欄位（固定）：
- **ID**：`L-001` 起，只追加。新教訓若和既有主題相同，改寫該主題條目（加一點細節、一行由來），並在「合併」欄記上新 ID。
- **日期**
- **規則**：一句話，以後一律怎麼做（digest 只抽這一行）。
- **細節**：分點的具體做法。
- **由來**：哪些事故，一件一句，附 E／F 編號。
- **對應測試或關卡**：測試檔、npm 指令、評估門檻或流程關卡；沒有寫「無」。
- **合併**：併進來的舊 ID。
- **相關**：其他 ID。

範例：

```
### L-999
- 日期：2026-10-28
- 規則：卡片驗收用 rank ρ 與中位數，不用固定範圍。
- 細節：
  - 尺度異常看中位數。
- 由來：驗收寫了「OVR 40–99」，四張卡被判 FAIL，其實是條件寫錯。
- 對應測試或關卡：預註冊審查
- 相關：R-005
```

### L-002

### L-004
- 日期：2026-09-05（2026-10-30 整併）
- 規則：回合與次數照實記帳：先累加次數再算比率，進攻籃板不開新回合，每種事件都要算到。
- 細節：
  - Monte Carlo 先累加次數再算比率，不平均每場比率。

### L-009

- 規則：加成與夾值的公式要單調、零和、可行：情境加成用加法，部分出手的加減對子集合零和，夾值衝突用有界單體投影。
- 細節：

### L-031
- 日期：2026-10-17（2026-10-30 整併）
- 規則：「變準」「不變差」都要附含所有雜訊層的區間，門檻要大於量過的雜訊底。
- 細節：
  - 模擬比較至少 8 組種子；運氣用群集標準誤或球隊＋seed 重抽區間，期望分差用運氣記帳降雜訊。
  - 預註冊的「變準」附配對 bootstrap 區間，下界 > 0 才算；只過單點門檻的記為「不比基準差」。
  - 模型選擇門檻對「相對 null 的增益」或 bootstrap 區間定，不用總 log-lik 的百分比；先用擬合季估各方法差距的量級，確認門檻跨得過。
  - 比較 S（或任何由 WinImp 算出的量）時，區間要含模擬抽樣層：對 sample index 也 bootstrap，或先用 checkpoint 拆半估 σ；兩個 seed 的差不能當噪音底線。預註冊先算「要分出 Δ 需要幾個樣本」；優先考慮改量尺（分差計分）降低每個 draw 的雜訊。
  - 「球隊層不變差」這類門檻，先用現行版本跑兩組 seed 量 MAE 的雜訊；門檻要明顯大於雜訊，否則加 seed，或固定每個事件的隨機數、用期望值帳本。預註冊寫出雜訊底的數字。
  - 主判準裡用到的模擬基準值，先用兩組不重疊的 seed 各量一次；兩組同號且差距小於要求的改變量才能用，否則換低雜訊量或加 seed。

### L-062
- 日期：2026-10-29（2026-10-30 整併）
- 規則：預註冊裡每個數字（門檻、範圍、公式、舉例、倍數）凍結前都寫出推導，並在不碰結果的資料上先算一次。
- 細節：
  - 門檻或合理範圍寫出怎麼從定義推出來（例如「約 100 次球權＋重置段 ≈ 117」）；推不出來就先用已揭露的聯盟彙總（不分組）核對。
  - 公式寫出每一項的單位，用一個代表球員代入算出數值寫在旁邊（收縮 k 要和 d 同單位）。
  - 樣本量門檻（人數、出手數）凍結前先數；只數曝光量，不碰結果變數，所以不違反 L-026。數的結果和指令寫進「已揭露」，預期值至少比門檻高 20%。
  - 每個校準目標要有自己活的旋鈕，並先量 legacy 和聯盟實際的差；兩個目標共用一個旋鈕時只能選一個當硬條件，另一個只報告。
  - 換尺、換錨點前，先寫明常態分布下頂端會變高還變低、約幾倍，用合成分布（不是真實資料）驗方向；方向和目的相反就不凍結。
  - 「重現某張卡到 ≤ ε」先用指定的輸入實跑一次；輸入是四捨五入過的顯示檔，就改指向未四捨五入的檔或放寬 ε。
  - 由資料換算的倍數／比例，在 phase 0 列出各項目的值並寫上下限（例如 clip 到 [0.25, 4]）；能從既有資料算出的事前預期，寫預註冊前先算。
