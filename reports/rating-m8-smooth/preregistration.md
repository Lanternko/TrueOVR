## 2. 驗收（2025-26 B 半，`fit_rating_m6`／`fit_rating_m7` 同口徑程式）
**P1 平滑度（主目標）**：B 半 TSA ≥ 20 且 FGM < FGA 的單場，把一顆沒進的兩分改成進（PTS＋2、FGM＋1，其他不變，M2 貢獻值用同一個 Rater 重算），評分變化的中位數與第 90 百分位。

一個 S 臂「通過」＝下列全成立：
- P1：第 90 百分位 ≤ 0.8 × M6 的第 90 百分位。
- 護欄對 M6：C1 比例 ≥ M6 − 0.05；A7 三項（自製 EPM ρ、DARKO ρ、前後半 r）各 ≥ M6 − 0.03；T3 ≤ M6 ＋ 5。
- 對 M4 照 E-150 §4：C2 前半（TSA ≥ 25、TS_lg − 0.08 ≤ TS < TS_lg，平均評分 − M4 > 0）、T4 ≥ 0.8、A4。
- 多個通過：取 P1 第 90 百分位最低者；相差 < 0.05 時依 S1 → S3 → S13 順序取前者（改動少優先）。都不過：維持 M6。
- 最後由使用者裁定。
