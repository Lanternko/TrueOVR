# 總評

**4/5（建議採用 R2-stats，R2-stats-rapm 不必）**

**核心結論**：判定 1、2 兩個臂都過。在沒看過的 1135 場測試上，加入統計向量的陣容 Transformer 比只用能力值的版本淨值誤差再降 17.6（stats）與 18.7（stats+rapm）；防守側翼的排名只改善一半、仍偏低，且與 2K26、薪水、進攻 RAPM 的相關變低。加 RAPM 特徵沒有再帶來可確認的好處（stats+rapm 比 stats 只多降 1.0，90% 區間 [-3.2, 1.3] 跨 0）。

**關鍵數據與例子**

五季測試（1135 場、22.8 萬回合；每 100 回合淨值的平方誤差，越小越好）：

| 比較 | 差值（點估計） | 90% 區間 | 門檻 | 判定 1 | 判定 2（三個守門指標） |
|---|---|---|---|---|---|
| R2-stats − R2-abil | -17.63 | [-24.7, -10.3] | ≤ −15.36 | 過 | 過 |
| R2-stats-rapm − R2-abil | -18.66 | [-25.6, -11.6] | ≤ −14.21 | 過 | 過 |

- 陣容 Transformer 贏過同特徵的加總基準（B1）：能力值 -28.1、stats -17.7、stats+rapm -17.7，區間都不含 0；單場勝負 Brier 從 B1-stats 的 0.2053 降到 0.2016。
- 防守側翼（最初的動機）只改善一半：防守 RAPM 相關 abil 0.282 → stats 0.402（E-225 是 0.194），但 Dean Wade 價值名次 #168、Tari Eason #182、Herbert Jones #210（共 276 人），仍遠低於卡片名次；Draymond Green 反而從 abil 的 #75 掉到 #197。
- 副作用：與 2K26 的相關 0.617 → 0.528、薪水 0.585 → 0.49、進攻 RAPM 0.707 → 0.626；卡片 OVR 與 BPM 的相關則微升（0.786 → 0.802、0.789 → 0.807）。

**要你決定的事**

- 兩個判定都過，沒有需要「停下交使用者裁定」的失敗項。建議**採用 R2-stats**（比 stats+rapm 少一組要維護的 RAPM 特徵，成績相同）；你 approve 後才接去個人價值與球隊評估。
- 防守側翼仍排得低，是否接受？(a) 接受，當作已知限制（建議：判定已過，再針對性調參會變成看過答案挑參數，L-026）；(b) 另開第三輪專攻防守特徵（需新預註冊）。
- 前向 2026-27 目前只有 100 場且全是凍結前打的，還沒有乾淨的前向證據；累積到足夠場數再補。

## 偏離與限制

- 前向用前一季（2025-26）特徵；RAPM 特徵在測試列與前向列用「全部 train 場次擬合」的 key none，與訓練時的 0 / 0-k 版本不完全同分布（照預註冊草稿）。
- 個人價值：卡 OVR 用 card-0.2.12c；網站 OVR 是 2026-11-02 版；2K26 欄混了開賣與賽季中快照；薪水取 BR contracts2025 的 y2；RAPM 取 card-0.2.10+E186 的 base-K6U-2025-26。Alex Caruso 上場 <1000 分鐘，不在母體。
- `npm test` 有 1 個失敗（`test/games_view_gate.py` 的 test_ot_labels，檢查 `scripts/games_view.py` 的 OT 字串），來自工作樹他處未提交的 games_view 修改，與 E-227 無關，未處理。
- manifest 的 sha256 是工作樹檔案（LF）的雜湊；git 在 Windows 可能存成 CRLF，以 git 取出位元組比對時可能不同。
