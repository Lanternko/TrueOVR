# E-276 抄截、干擾、蓋帽獨立成防守欄位

預註冊：`prereg.md`（commit 3a2957e）；程式 `e276_eval.py`；數字在 `results.json`。

# 總評

**1/5（不採用）**

核心結論：把抄截、干擾、蓋帽拆成獨立欄位加進 DEF，預測下季防守 RAPM 沒有變準（合併 ρ D0 0.422、D8 三項全加 0.417）；只加蓋帽（D8c）三折都小贏（0.429，+0.007），方向穩定但遠低於 +0.03 門檻。

- 抄截、干擾的權重每季正負來回跳（如抄截 +0.31 → −0.06），代表它們在 pressure 之外沒有穩定的額外資訊；蓋帽三季都是正的。
- 蒸餾路線加了新欄位後 Caruso 回到第 3 名（E-275 只用能力值時是 78），證明 T 看重的確實是這些數據，但整體仍輸 D0。

**要你決定的事**

- 建議不加抄截、干擾欄位（已在 pressure 裡，拆開沒有用）。
- 蓋帽是唯一方向穩定的訊號，但增益很小；可選：和 E-274 的 D1（兩側加分）一起當顯示欄小改，或維持現行。
