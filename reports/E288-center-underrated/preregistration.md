## 2. 加分式與實驗臂
`ovr' = ovr + λ · sd(ovr) · P`，λ ∈ {0, .05, .1, .2, .3, .5, .75, 1.0}，每折用另外三折 Δρ_all 平均最大挑 λ。每季每臂的 P 縮放到與 CPOS 指標相同的均方根（L-062，避免變異數偏袒網格）；CPOS 本身不縮放。

| 臂 | P（縮放前） | 目的 |
|---|---|---|
| **ROLE（主臂）** | clip(mean(z(scr36), z(con2_36), z(box36)), 0, 1.5) | 不靠出手的長人貢獻：掩護助攻、兩分干擾出手、卡位，不看位置 |
| ROLE_BIG | ROLE × 1[pos ∈ {PF, C}] | 只給前場長人 |
| SCR | clip(z(scr36), 0, 1.5) | 單測掩護助攻 |
| CON | clip(z(con2_36), 0, 1.5) | 單測禁區干擾出手 |
| BOX | clip(z(box36), 0, 1.5) | 單測卡位 |
| **CPOS（對照）** | 1[pos = C] | 純位置先驗：差距只是「中鋒」標籤嗎 |
| **HGT（對照）** | clip(z(heightInches), 0, 1.5) | 純身高 |
| **SHUF（對照）** | ROLE 在每季球員間隨機打亂，300 次，seed 20261288 | 確認改善不是雜訊 |

## 3. 指標
1. **整體排序**：四折人數加權 Δρ_all（Spearman(ovr', y) − Spearman(ovr, y)），配對 bootstrap 90% 區間（2000 次，seed 20261288），正的折數；後衛 Δρ_G。
2. **結構目標（中鋒缺口）**：四折合併，C 的平均「pct(y) − pct(ovr)」（正＝OVR 低估 C）在 λ 前後；另報 PF。
3. **R-001 頂端長人**：2025-26 卡在 λ* 下前十名的 PF／C 只能是 Wembanyama、Giannis、Jokić、Chet（原本就在的不算違反；新增別的長人進前十＝違反）。
4. **代表球員（2025-26 卡，λ*）**：Steven Adams、Myles Turner、Ivica Zubac、Jakob Poeltl、Isaiah Hartenstein、Rudy Gobert、Jarrett Allen 名次變化；以及前 30 名被擠掉 > 10 名的人數。

## 4. 判定（ROLE、ROLE_BIG、SCR、CON、BOX 各自判）
- `adopt_candidate`：全部成立
  1. Δρ_all ≥ +0.005 且 90% 下界 > −0.005；
  2. 四折 ≥ 3 折 Δρ_all > 0；
  3. 中鋒缺口（若基準 > 0）縮小 ≥ 一半，且 Δρ_G ≥ −0.01；
  4. R-001 不違反，前 30 名掉 > 10 名的人 ≤ 1。
- `structural_partial`：3、4 成立，Δρ_all ≥ −0.003 且下界 > −0.01（結構修好、整體不弄壞；R-178 允許分步）。
- 其他 `reject`。
- 與 CPOS 的差（配對 bootstrap）照實報告：若候選臂不勝 CPOS，結論寫「缺口主要是位置先驗，hustle 特徵沒有額外訊號」。
- 若基準中鋒缺口 ≤ 0（評估台上 OVR 並沒有低估中鋒），結論直接寫「橫斷面看到的低估在前瞻台上不成立」，各臂只看 1、2、4。
