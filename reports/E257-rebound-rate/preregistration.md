# E-257 預註冊：球隊籃板率能不能補 T 的殘差

日期：2026-11-07　狀態：凍結（R-165）

## 問題
POR 診斷第二輪：進攻籃板率 31.7%、對手 23.8%（聯盟 27.3%），每場約 +3.2 分；F-081 模擬裡個人對隊伍進攻籃板率的影響只有實測約一半（Clingan 差最多）。假設：T 系統性低估籃板好的球隊。
「本季到目前為止的球隊籃板率」能不能預測 T＋R-171 殘差之後還剩下的每場分差誤差？

## 基準 B0
E-253 K10：`m = m_T + R_home − R_away`，`R = Σ(實際−(m_T±H)) / (n+10)`，H＝2.5、σ＝12，同日不互用（同 E-254）。

## 特徵（只用比賽日 < 該場的已完賽比賽，季累積）
- `orb`＝ΣOREB／Σ(OREB＋對手 DREB)：自己的進攻籃板率。
- `drb`＝Σ對手 OREB／Σ(對手 OREB＋自己 DREB)：讓對手拿到的進攻籃板率（越低越好）。
- 每項對「到該日為止的聯盟平均」置中，再收縮 `n/(n+5)`（n＝已打場數；n＝0 → 0）。每場特徵＝主隊 − 客隊。
- 籃板用球員籃板合計（不含團隊籃板）：2025-26 box `reboundsOffensive／reboundsDefensive`，2026-27 `team-games.json` OREB／DREB。

## 臂（OLS 無截距，擬合 `r = 實際分差 − (m_B0 + H)`）
- **SORB**：orb。
- **SDRB**：drb。
- **SREB**：orb、drb 兩係數。
新預測 `m = m_B0 + β·Δx`，勝率 Φ((m+H)/σ)。

## 資料
- 2025-26 主測：E-228 `pred-T-2526`（季前凍結 T）＋ `dnp-2025-26-raw` box。訓練＝比賽日 < 2026-01-01；測試＝≥ 2026-01-01。
- 2026-27 前向：E-246 `t_T1` 賽前預測（同 E-253／E-254 J2），β 用 2025-26 整季重擬後凍結。
- 揭露：POR 本季籃板已在診斷看過（動機）；其他隊沒看過。2025-26 隊層級籃板與殘差的關係沒看過。

## 判定
- **J1**：2025-26 測試段 ΔBrier（臂 − B0），配對場次 bootstrap 10000、rng 20261107；3 臂 Bonferroni → 98.33% 區間，上界 < 0 算過。採用臂＝通過者中點估計最低。
- **J2**：採用臂 2026-27 前向 ΔBrier 點估計 ≤ 0。
- 兩道過 → 建議採用；J1 過 J2 不過 → 3/5 交使用者；J1 不過 → 不採用。

## 只報告
- β 與標準誤（換算成「進攻籃板率 +3 個百分點 → 每場幾分」）。
- 季層級（30 隊）：2025-26 整季籃板率 vs 整季平均殘差（實際 − T）相關；2024-25 籃板率 vs 2025-26 殘差相關。
- 2026-27 現在 POR 等隊的調整量。
