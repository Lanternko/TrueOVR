# 總評

**1/5 失敗**（主目標「讓傳球偏高變小」沒有達成；順便薪水那一項還略退步）

**這次目標**

把傳球從「各位置不同斜率」改成「全位置共用一條斜率」（臂 A），看能不能修掉 E-179 發現的「卡片把傳球高的球員排得比下季 RAPM 高」。照凍結預註冊，用 2024-25 原點卡對 2025-26 RAPM 判定（不等 2026-27）。

**進步了什麼**

1. 傳球的「前鋒 vs 後衛」差距縮小了：前鋒的傳球偏高少一點點，後衛多一點點，兩邊拉近（2022-23、2023-24、2024-25 三個原點方向一致）。
2. 傳球斜率不再因位置而不同：PF 從每 10 點 0.53 降到 0.36，SG 從 0.20 升到 0.36，其他位置都落在 0.36 上下。

**退步了什麼**

1. **主目標沒動**：全人群「傳球越高、卡片越比下季 RAPM 排得高」的程度，K0 與 A 一樣（相關 −0.31 對 −0.30），差距在雜訊裡。前鋒變好的部分剛好被後衛變差抵消。
2. 和薪水的相關 .590 → .585、和 2K 的 .766 → .763、隊內分鐘與 OVR 的相關 .645 → .636：都是小幅下降，其中薪水那項在預註冊的容忍範圍外，不達標。
3. 前鋒的 creation 偏差（E-179 看到的另一件事）A 沒有處理到，和預期一致。
