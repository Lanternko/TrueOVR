# E-254 預註冊：球隊出手結構能不能補 T 的殘差

日期：2026-11-07　狀態：凍結（R-165：Claude 自訂標準直接凍結開跑）

## 問題
POR 診斷（`reports/por-offense-diag/report.md`）：三分出手佔比第 2、中距離得分佔比第 30，屬性只有投籃準度、沒有出手選擇。
「本季到目前為止的球隊出手結構（三分出手佔比、中距離出手佔比、罰球率）」能不能預測 T＋R-171 殘差之後**還剩下**的每場分差誤差？

## 基準 B0
E-253 K10：`m = m_T + R_home − R_away`，`R = Σ(實際−(m_T±H)) / (n+10)`，H＝2.5、σ＝12，同日不互用。

## 特徵（只用比賽日 < 該場的已完賽比賽，季累積）
- `f3`＝ΣFG3A／ΣFGA；`fmid`＝Σ(2PA − 禁區出手)／ΣFGA；`fft`＝ΣFTA／ΣFGA。進攻（自己出手）。
- 防守版（分支臂用）：同三項，用對手對這隊的出手。
- 每項對「到該日為止的聯盟平均」置中，再收縮 `n/(n+5)`（n＝該隊已打場數；n＝0 → 0）。
- 每場特徵＝主隊值 − 客隊值。

## 臂（係數 β 用 OLS、無截距，擬合 `r = 實際分差 − (m_B0 + H)`）
- **S3**：f3。
- **SMID**：fmid。
- **SALL**：f3、fmid、fft。
- **SALLD**（分支：防守端出手結構也算）：SALL＋三項防守版，共 6 個係數。
- 新預測 `m = m_B0 + β·Δx`，勝率 Φ((m+H)/σ)。

## 資料
- **2025-26 主測**：E-228 `work/pred-T-2526.json`（T2425 權重、季前特徵；T 與本實驗都沒看過 2025-26 的出手結構）。box 出手來自 `data/season-source/dnp-2025-26-raw/boxscore_*.json.gz`（`pointsInThePaintAttempted` 當禁區出手）。
  - **訓練**：比賽日 < 2026-01-01 的場次擬合 β；**測試**：≥ 2026-01-01（特徵仍用整季累積到賽前）。
- **2026-27 前向**：E-246 `work/t_T1.json` 賽前預測＋比分（同 E-253 J2），β 用 2025-26 **整季**重擬後凍結；三分／罰球出手來自 `team-games.json`，中距離來自 NBA.com `leaguedashteamshotlocations`（DateTo＝前一天、季累積，Mid-Range FGA）。
  - 揭露：2026-27 的 POR 出手結構已在診斷看過（這是動機）；其他隊沒看過，β 不在 2026-27 擬合。

## 判定（R-117 兩類）
- **J1（主目標）**：2025-26 測試段 ΔBrier（臂 − B0），配對場次 bootstrap 10000、rng 20261107；4 臂 Bonferroni → 97.5% 區間，上界 < 0 算過。採用臂＝通過臂中點估計最低者。
- **J2（不壞）**：採用臂在 2026-27 前向的 ΔBrier 點估計 ≤ 0（區間只報）。
- 兩道都過 → 建議採用；J1 過 J2 不過 → 3/5 交使用者；J1 不過 → 不採用。

## 只報告不判定
- β 與標準誤（換算成「三分出手佔比 +5 個百分點 → 每場幾分」）。
- 季層級：2024-25 各隊出手結構 vs 2025-26 整季平均殘差（實際 − T）的相關（30 隊）。
- 現在 POR 等隊的調整量。
