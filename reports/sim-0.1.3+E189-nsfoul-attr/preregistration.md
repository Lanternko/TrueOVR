# E-189 預註冊（草稿）：非投籃犯規防守者屬性

- 日期：2026-11-01；狀態：草稿，使用者回「好」才凍結（凍結時寫 sha256）。
- 依據：R-125（使用者裁定加屬性、重開 F-129 額度 3）、R-117（問題卡與停損）、R-115（耦合參數一次重解）。
- 基準：sim 0.1.3（`reports/player-impact-v29/benchmark.mjs` options()，R-120）。

## 1. 問題與已揭露
- F-129：中鋒罰球防守去雜訊散布 模擬／實測 0.56，缺口約九成在非投籃犯規罰球（實測 0.299、模擬 0.029）。
- 引擎現況（v40 起，`reports/player-impact-v40/engine.mjs:49`）：非投籃犯規機率＝`ordinaryContactProbability(進攻陣容)`，犯規者固定是被犯規者的對位防守者，防守者是誰不影響。
- F-129 D2：實測每 100 防守回合，非投籃犯規分半信度 0.71、投籃 0.76，兩者去雜訊相關 0.21 → 另立屬性，不沿用 β。
- 已看過上面所有數字；下列設計在看任何 E-189 模擬結果前定死。

## 2. 屬性（輸入，無自由參數）
- 對象：2025-26 有防守回合的所有球員。
- 原始率 r_i＝非投籃個人犯規（descriptor 空、loose ball、take；排除 flagrant、offensive、technical）／防守回合 ×100，用 `d2_propensity.py` 同口徑。
- 收縮：r̃_i＝(n_i·r_i＋k·r̄)／(n_i＋k)，n_i＝防守回合，k 由分半信度反推（信度＝n/(n+k) 在人群中位 n 時成立），算一次定死。
- γ_i＝ln(r̃_i／r̄)，再以防守回合加權平均調成 0（聯盟量不變）。沒資料或補位球員 γ＝0。
- 樣本外：建屬性只用**單數場**（`int(gameId)%2==1`），判定只對**雙數場**的實測答案；再交換一次，兩邊都報、以平均判定。

## 3. 機制（只有這一種）
- 非投籃犯規發生機率 ×＝ (1/5)·Σ_{j∈場上防守 5 人} exp(γ_j)。
- 犯規者改為依 exp(γ_j) 比例在場上 5 人中抽（被犯規者照舊由進攻端權重決定）。
- 投籃犯規 β、其他一律不動。
- 重解（R-115，一次做）：非投籃犯規基準倍率使聯盟非投籃犯規罰球每隊每場 =0.1.3 ±1%；之後照 E-166 的方法重解 c、pace，使聯盟得分、回合、總罰球對齊 0.1.3。校正 seed 20261190–205；判定 seed 20261210–241（32 個，沒用過）。

## 4. 判定
硬條件（R-117 只兩類）：
- **j1 主目標修到**：150 名 ≥1000 分鐘球員，模擬逐人非投籃犯規率 對 實測雙數場（交換後平均）：Pearson r ≥ 0.45，且加權斜率在 0.7–1.3。基準 0.1.3 同算一次報告。
  - MDE：單數場建的屬性對雙數場實測，r 上限約等於半季信度 0.71；n=150 時 r 的 SE 約 0.07，MDE 約 0.14。預期 0.1.3 接近 0、E-189 約 0.6，遠大於 MDE。
- **j0 沒弄壞**：npm test 過；預設路徑重現逐場相同（同 seed 跑兩次）；聯盟得分、回合、總罰球對 0.1.3 差 <1%；30 隊淨分差 MAE 變差不超過雜訊底 2 倍（E-140 0.143 → 0.286）。
只報告／權衡（不否決）：
- 中鋒罰球防守去雜訊散布比（F-129 D0 管線；bootstrap 區間太寬，0.10–1.05，不當門檻）、非投籃罰球分量的中鋒比值（D1）。
- 30 隊造罰球／讓罰球散布（F-130）、E-067 S 偏袒長人、WinImp 名次對樣本外答案的 Spearman、36 名防守型非中鋒名次。
