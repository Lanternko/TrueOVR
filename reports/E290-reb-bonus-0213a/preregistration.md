## 2. 加分式與臂
`ovr' = ovr + λ · sd(ovr) · P`，λ ∈ {0, .05, .1, .2, .3, .5, .75, 1.0}，每折用另外三折 Δρ_all 平均最大者（留一折）。P 縮放到與 CPOS 指標相同均方根（L-062），CPOS 不縮放。

| 臂 | P（縮放前） |
|---|---|
| **REBc（主臂）** | clip(mean(z(rebound), z(orebPct), z(drebPct)), 0, 1.5) |
| CON（對照） | clip(z(con2_36), 0, 1.5) |
| MIX | 0.5·REBc 縮放後 + 0.5·CON 縮放後，再縮放（REBc 與 CON 各半） |
| CPOS（對照） | 1[pos = C] |

## 3. 指標
1. 整體排序：四折人數加權 Δρ_all，配對 bootstrap 2000 次（seed 20261290）90% 區間，正折數；後衛 Δρ_G。另單列 2025-26 折。
2. 結構：四折合併 C 的 pct(y) − pct(ovr) 缺口前後；PF 一併報。
3. 2025-26（0.2.13a）卡在 λ*（四折全用 Δρ 平均最大者）下：前十、前十新增長人、前 30 掉名者、代表中鋒名次（Gobert、Allen、Hartenstein、Zubac、Poeltl、Turner、Robinson、Kessler、Adebayo、Sabonis、Sengun、Mobley、Adams）。

## 4. 判定（REBc、CON、MIX 各自判）
- `adopt_candidate`（全部成立）：
  1. Δρ_all ≥ +0.005 且 90% 下界 > −0.005；
  2. 四折 ≥ 3 折 Δρ_all > 0；
  3. C 缺口（基準 > 0 時）縮小 ≥ 一半，且 Δρ_G ≥ −0.01；
  4. 前十新增的 PF/C 只容許 R-182 範圍內的人（Wembanyama、Giannis、Jokić、Chet、Mobley；其他新增長人算違反），且前 30 名掉 > 10 名的人 ≤ 1。
- `structural_partial`：3、4 成立，Δρ_all ≥ −0.003 且下界 > −0.01。
- 其他 `reject`。與 CPOS 的差（配對 bootstrap）照實報；若不勝 CPOS，結論寫缺口主要是位置先驗。
- 若基準 C 缺口 ≤ 0，結論寫「低估在此台子不成立」，只看 1、2、4。
- 產出候選卡：有 adopt_candidate 時用 λ*（凍結）產 `reports/card-0.2.14-cand/`；多臂過時優先序 REBc > MIX > CON；都不過不產卡。
