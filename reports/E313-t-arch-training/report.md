# E-313 報告：陣容 Transformer 架構、損失函數與多折集成升級（球隊＋個人雙軌）

- 日期：2026-11-27
- 預註冊：`reports/E313-t-arch-training/prereg.md`（sha256 `93bf29e9c5fb1359c357f39b741a5e1a14ff9e5e47c45aa416fdbbf349668315`）
- 運算環境：雙 RTX 5090（`gpu5090` 跑 B0/A1/A2，`gpu5090-3` 跑 A3/A4），全部沿用現行 41 欄 `stats` 特徵，零新增外部資料依賴。

## 核心結論
- **雙軌全過勝出臂：`A1`（現行 `LineupNet`＋5-fold CV 10 模型集成＋A/B 雙向對稱增強）**。
  - **球隊（2,460 場盲測）**：`prior` 合併 Brier **0.21521 → 0.21477（−0.00044**，90% CI `[−0.00112, +0.00024]`），2024-25（−0.00077）與 2025-26（−0.00013）兩季皆贏；勝場 MAE `6.598 → 6.587`，分差 MAE `11.677 → 11.653`；`same` 合併 Brier `0.18900 → 0.18898`（非劣略勝）。
  - **個人（兩季跨季樣本外 EPM，n=605）**：`T-NET` **0.6489 → 0.6585（+0.0096）**、`T-OFF` **0.6216 → 0.6314（+0.0098）**、`T-DEF` **0.6230 → 0.6314（+0.0084）**，兩季全贏；與 card 0.2.15 混 0.5 後的線上顯示值 `B50-NET` **0.7745 → 0.7802（+0.0057）**，`B50-DEF` **0.7861 → 0.7913（+0.0052）**。
- **次佳臂 `A2`**（A1＋分差 loss＋四要素輔助＋得分/分差早停）：同樣通過雙軌主關卡，且單模型 Brier 變異最低（SeedSD `0.00319 → 0.00254`），但 `prior` Brier 增益（−0.00025）與個人 EPM 增益（+0.0057）皆略低於 `A1`。
- **加性分解架構 `A3`／`A4`**：個人準度大幅躍升（`A4` `T-NET +0.0120`；`A3` `B50-NET 0.7745 → 0.7882`，且 `AdditiveHead` 直接輸出與 3,000 次 T-swap 相關 0.996–0.9997），但因容量放大（d=96）在跨季 `prior` 出現過擬合與單模型變異暴衝（SeedSD 0.014–0.024），球隊 `prior` Brier 退步 +0.0025～+0.0029，不進球隊候選；其架構值得另開個人模型／強正則小容量實驗。
