# E-313 預註冊：陣容 Transformer 架構、損失函數與多折集成升級（球隊＋個人雙軌）

- 凍結日：2026-11-27（R-165：自訂標準直接凍結開跑；凍結後不改動本檔，任何增補另開 errata 並引本檔 sha256）。
- 問題：現行線上陣容 Transformer `T`（E-227 `LineupNet`，d=64、2 層、4 頭）同時驅動「球隊評分（戰力／勝負／勝場，R-160）」與「個人 OFF／DEF 換人值（E-287、R-181）」。過去實驗（E-227～E-312）皆在固定極簡架構下微調輸入欄位，存在四個結構瓶頸：(1) 只用 fold 1-4 訓練、永遠丟棄 fold 0 的 20% 歷史比賽，且無 A/B 對稱增強；(2) `l_tov + l_orb` 佔總 loss 一半權重且主導早停，未直接優化分差 `net margin`；(3) 黑盒 Transformer 將個人主效應與陣容交互混在一起，造成單 seed 變異大；(4) 缺乏隊內協同與隊間對位的明確結構先驗。
- 目標：在不新增任何特徵欄位（沿用現行 41 欄 `stats`，與線上 `e229_live` 100% 相容）的前提下，驗證架構、損失函數與 5-fold CV 集成能否**同時提升跨季球隊勝負準度與跨季個人換人影響力準度**。

## 五個對照臂（同一套 41 欄 `stats` 特徵，同 5090 環境重訓，G3）

| 臂 | 說明 | 模型數（訓練資料） | 損失函數與早停 |
|---|---|---|---|
| **B0** | 現行基準 `LineupNet`（d=64, 2L, 4H, lr=1e-3, wd=0.1） | 5 seed（fold 1-4 訓，fold 0 早停；80% 資料） | `l_pts + l_tov + l_orb`，總和早停 |
| **A1** | `LineupNet`＋**5-fold CV 集成＋A/B 對稱增強** | 5 fold × 2 seed＝10 模型（100% 資料，每模型 80/20 早停） | 同 B0 |
| **A2** | A1＋**淨勝分差 loss＋輕量四要素輔助＋得分/分差早停＋Cosine LR** | 10 模型（5 fold × 2 seed） | `l_pts + 0.5*l_net + 0.15*(l_tov+l_orb+l_efg+l_ftr)`；早停看 `l_pts + 0.5*l_net` |
| **A3** | A2＋**殘差分解架構 `DecomposedLineupNet`**（Player MLP＋Feature Dropout 0.1＋加性個人攻防主效應頭＋2 層 Pre-LN Transformer 交互殘差，d=96） | 10 模型（5 fold × 2 seed） | 同 A2 |
| **A4** | A2＋**嚴格對稱隊內／隊間注意力分解架構 `TeamSelfCrossNet`**（Player MLP＋加性個人主效應頭＋1 層隊內 Self-Attn＋1 層隊間 Cross-Attn 交互殘差，d=96） | 10 模型（5 fold × 2 seed） | 同 A2 |

- 訓練超參數（凍結）：batch size=1024，max_epochs=60，patience=8（B0 維持現行 patience=5、固定 lr=1e-3）；A2/A3/A4 使用 AdamW（lr=1e-3，wd=0.1，gradient clip 1.0，CosineAnnealingLR 至 1e-5）。

## 雙軌嚴格樣本外驗收（G4，訓練完全不見測試季）

### 軌道一：球隊準度（跨兩季共 2,460 場盲測，同 E-311 / E-228 口徑）
- **2024-25 盲測**（1,230 場）：模型只用 2021-22～2023-24 訓練（`last=2023-24`）。預測視角：
  - `prior`（主要，嚴格賽前）：用 2023-24 賽前特徵表。
  - `same`（輔助，消除季間傷病／轉隊漂移，檢驗純模型上限）：用 2024-25 同季特徵表。
- **2025-26 盲測**（1,230 場）：模型只用 2021-22～2024-25 訓練（`last=2024-25`）。同樣報告 `prior`（2024-25 表）與 `same`（2025-26 表）。
- 推論設定：所有臂共用同一組 Gumbel top-k 陣容抽樣（N=2000，rng `[228, game_i]`），ensemble 取所有模型邊際平均，勝率 `p = Φ((margin + 2.5) / 12)`。
- 指標：
  - **主指標**：兩季合併 `prior` Brier 差（臂 − B0），附分季重抽 2000 次成對 bootstrap 90% 區間（seed 20261313）。
  - **輔指標**：兩季合併 `same` Brier 差、勝場 MAE 差（`prior` 與 `same`）、30 隊勝場 Spearman、兩季分季 Brier。

### 軌道二：個人準度（T-swap 攻守淨值，同 E-287 口徑，完全樣本外）
- 抽樣設定：3000 組隨機 10 人陣容（seed 20261108，所有臂共用同一批陣容），計算每位球員的 `T-OFF`（換進時本隊每 100 回合得分）、`T-DEF`（換進時對手每 100 回合失分取負）、`T-NET`（`T-OFF + T-DEF`）。
- 兩組跨季樣本外 EPM 驗收（權重同 E-287：`stintPoss ≥ 1000` 且乘以分鐘曲線 `wfun(mp)`）：
  1. `train ≤ 2023-24` → 2023-24 球員特徵算 T-swap → 測 **2024-25 EPM（O、D、TOT）** Spearman。
  2. `train ≤ 2024-25` → 2024-25 球員特徵算 T-swap → 測 **2025-26 EPM（O、D、TOT）** Spearman。
- 2K27 與人類直覺驗收（2025-26 人群，使用 `train ≤ 2024-25` 模型）：
  - T-swap OFF／DEF 對 2K27 攻／防指標 Spearman，以及與現行 `card` 0.2.15（E-287 線上規則 `w=0.5`）混合後的 OFF／DEF Spearman。
  - 代表性球員檢查：Durant vs VanVleet DEF 排序、前十長人 DEF 排序、T-NET 前十名。
- **附加診斷（僅報告，不進主判準）**：A3／A4 直接從 `AdditiveHead` 讀出的個人 `(o_i, d_i)` 與完整 T-swap 的相關度與 EPM 準度比較（檢驗加性頭本身是否可免抽樣直接產出高品質個人攻防值）。

## 凍結判定規則
候選臂（A1～A4）各與 B0 比較：
1. **球隊主關卡（Team Gate）**：
   - `prior` 兩季合併 Brier 差 ≤ 0（90% 上界 < 0 為「顯著變準」，點估計 < 0 且區間跨 0 為「方向對／非劣」），且
   - `same` 兩季合併 Brier 差 ≤ 0，且
   - 兩季 `prior` 分季 Brier 皆不得退步超過 +0.0010。
2. **個人主關卡（Player Gate）**：
   - 兩季合併樣本外 EPM Spearman（人數加權平均）的 `T-NET` ≥ B0（不退步），且 `T-OFF` 與 `T-DEF` 各自不得退步超過 −0.005。
   - 若 `T-NET` 合併 Δρ ≥ +0.005 且 `T-OFF`、`T-DEF` 皆 ≥ B0 − 0.002，判為「個人顯著變準」。
3. **勝出規則**：
   - 在同時通過「球隊主關卡」與「個人主關卡」的候選臂中，依「`prior` 合併 Brier 最低」選出最佳候選臂；若多臂 `prior` Brier 差距 < 0.0003，選結構較簡或個人 `T-NET` 較高者。
   - 若有臂只在單軌顯著贏而另一軌非劣（無實質退步），亦列為 adopt_candidate 交使用者裁定；若全部未過，維持 B0。
