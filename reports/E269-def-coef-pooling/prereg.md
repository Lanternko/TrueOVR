# E-269 預註冊：卡片 pred0 的防守能力係數要不要跨位置共用

- 日期：2026-11-08。角色：role-card。來源：使用者問「防守三項係數是否該跨位置共用」。標準由執行者自訂並直接凍結（R-165）。狀態：已凍結（2026-11-08，凍結時尚未看任何臂的結果）。
- 凍結前只讀過程式碼，沒有看過任何臂的擬合係數、ovr 或對目標的相關。

## 0. 前提更正（讀程式碼得到，不是結果）
`calibrate_wing_t.py` 的 pred0 設計（`position-interactions`、ridge λ=1、權重 1/(mc+s2)）：16 個屬性的 z 值主效應**所有位置共用**；位置 dummy × z 的交互項只有 `INTERACT = [long, short, pass, rebound, help]` 五個（C 當基準），**沒有位置截距**。所以防守三項裡 `onBall`、`pressure` 本來就跨位置共用，現行唯一隨位置變動的防守係數是 `help`（護框）。因此 A1「防守三項共用」實際等於「拿掉 help 的位置交互」。

## 1. 臂（全部只改 pred0 的擬合；bonus、align、H1 封頂、perGame、OVR 對應、用人層一律照 E-164 S 路徑重跑）
| 臂 | pred0 設計與擬合 |
|---|---|
| A0 | 現行：主效應＋{long, short, pass, rebound, help} × 位置 dummy（C 基準）；全部欄 ridge λ=1 |
| A1 | A0 拿掉 help × 位置（防守三項全共用）；其餘交互不變 |
| A2 | 全部係數共用：只有 16 個主效應＋4 個位置 dummy 截距（PG、SG、SF、PF；C 基準），全部欄 ridge λ=1，無任何位置×屬性交互 |
| A3 | 設計同 A0；交互欄（上述五個×四位置）改用獨立 ridge λ_int，主效應欄維持 λ=1。λ_int 由「該卡原點自己的訓練資料」內 5 折×10 次 CV 的加權 R²（原檔 `cv_score` 同口徑）從網格 {1, 3, 10, 30, 100, 300, 1000} 挑最大者；λ_int=1 即 A0。λ_int→∞ 即交互全為 0（共用） |
| A4 | A1 設計；`help`、`onBall`、`pressure` 三個主效應係數加下界 ≥ 0（有界加權 ridge，scipy `lsq_linear` 增廣系統；截距不罰） |

- 擬合資料、權重、s2 迭代、z 標準化（全體列的平均與標準差）全部沿用原檔；只有設計矩陣與罰則不同。
- 4 個原點 2022-23、2023-24、2024-25、2025-26 各自重建整張卡（E-164 S 路徑＝多加 `--dropAttr stamina`；T6 候選 pkl、三張部件卡、Y0 用人層全部照 E-164）。
- **重現檢查（硬）**：A0 重建的 `ranking.csv` sha256 必須與 `card-0.2.9+E164-no-stamina/ranking-S-<原點>.csv` 逐位元相同，否則整個實驗作廢、先修驅動。

## 2. 樣本外評估（目標在卡原點的資料之外）
- 卡原點 t → 預測 t+1 季。完整季折：2022-23→2023-24、2023-24→2024-25、2024-25→2025-26（共 3 折，≥ 2）。2025-26→2026-27 季中折（poss2627 ≥ 200，資料截至 2026-11-06，同 E-267／E-268）只報告，不進判定（季中資料未完整）。
- 人群與預測值：同 E-262/E-268 的 `card_season`（MIN ≥ 500、名字唯一）、預測值＝各臂 ranking-S 的 `ovr`。目標＝自製 EPM（`epm_<s>.csv`，stintPoss ≥ 1000）net × `P.wfun(mpg 目標季)`，亦即「下季整體影響」。
- **主指標**：R²（ovr 與目標的 Pearson r 平方）與 Spearman ρ（全人群）。判定用 R²；ρ 同表報告。
- **次指標**：DEF 分數對下季防守 RAPM（`rapm-<s>.json` 的 D × W，poss ≥ 1000；先檢查 net≈O+D 以確認 D 的符號，符號反了就取負，檢查是資料事實不是結果）的 Spearman ρ。DEF 分數＝onBall＋help＋pressure 三項貢獻（各位置係數 × (屬性 − 人群平均)，係數照 `season_nav.off_def` 做法對該臂 ranking-S 的 pred0 逐位置最小平方還原）＋ defenseBonus − 人群平均 defenseBonus。
- 各折權重＝該折主指標有效人數。「合併」＝依人數加權平均；ΔX＝臂 − A0。

## 3. 採用門檻（每臂各自判定；全部成立才算過）
1. 合併 ΔR² ≥ +0.005（相對 A0）；
2. **每一個**完整目標季 ΔR² ≥ 0（不允許任何一季比 A0 差）；
3. 合併次指標 Δρ_DEF ≥ 0（不下降）。
- 多臂皆過：取合併 R² 最高者。沒有臂過：維持 A0。
- 只有次指標進步（合併 Δρ_DEF ≥ +0.005）而 |合併 ΔR²| < 0.005：結論「只可用在 DEF 顯示欄」（不動卡片 OVR）。
- 本實驗只做判定，不改現行卡、不發版、不改 inseason 版本；是否採用交使用者。
