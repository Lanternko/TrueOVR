# 總評

**3/5（建議不採用「防守係數共用」；A3 過了凍結門檻但證據偏弱，建議先不上線）**

核心結論：把防守係數（help）全位置共用（A1／A4）或全部能力值係數共用（A2），樣本外**變差**（合併 ΔR² −0.006），不能當成修 Durant／SF help 偏低的解法；只有「分位置係數往共用值做 ridge 收縮」（A3）過了凍結的採用門檻（ΔR² +0.0074、三個完整目標季全正、DEF ρ 持平），但 90% 區間 [−0.0008, +0.0156] 仍碰到 0，且它不是靠「防守」贏的。

**關鍵數據與例子**

主指標＝卡 OVR 對下季「整體影響」（自製 EPM × 出賽權重）的 R²；三個完整目標季（2023-24、2024-25、2025-26）合併 A0 R²＝0.539、ρ＝0.702，次指標 DEF 分對下季防守 RAPM ρ＝0.422（A0）。下表 Δ 都是臂減 A0。

例子：2025-26 卡原點的 DEF 分名次（379 人中，名次小＝防守好），**Kevin Durant** A0 第 320 → A1 第 275／A2 第 279／A3 第 290，**Victor Wembanyama** 四臂皆第 1，**Rudy Gobert** 第 8 → 7／7／7，**Alex Caruso** 第 3 → 3／2／2，**Stephen Curry** 第 234 → 216／214／224，**Alperen Sengun** 第 216 → 214／212／226，**Amen Thompson** 第 14 → 15／15／15。A0 的 SF help 係數每 10 點只有 +0.029（SG +0.012），共用後 +0.256（A3 收縮後 SF +0.179、SG +0.148），Durant 因此往前挪約 30–45 名，但仍排在後段（防守三項對他本來就是負貢獻）。Fred VanVleet 不在任何一個原點的卡片名單內（沒有 ≥ 500 分鐘的卡片列），無法列名次。

- **防守共用沒有帶來預期的改善**：A1／A2 的 DEF ρ 只多 +0.004～+0.009，逐季方向不一致（A1 為 +0.040／−0.018／−0.006），而 OVR 預測更差（A1 的 90% 區間 [−0.012, −0.0001]）。分位置 help 係數小的現象不像單純擬合假象，至少拿掉它不會更準。
- **A3 的進步不在防守上**：A3 同時收縮 long、short、pass、rebound、help 五種交互項，三折 DEF ρ 為 +0.035／−0.017／−0.009，沒有改善；我沒有拆開是哪個交互項帶來 R² 增益，所以不能說是 help 貢獻的。A3 對 2025-26 卡 OVR 的改動小（最大 3.8 點、5 人 ≥ 3 點），對 2022-23 卡最大 15 點、35 人 ≥ 3 點。
- **旁測：把 rebound＋身高加進 DEF 顯示欄對防守 RAPM 反而略降**：A0 ρ 0.422 → 0.416（−0.006），A1／A2／A3 分別 −0.014、−0.019、−0.010。Gobert 這類人因此名次前移（第 8 → 第 5），Curry 往後掉（第 234 → 第 316），不建議加。

**要你決定的事**

1. 防守係數共用（A1／A2／A4）：建議**不採用**，A0 現行分位置係數維持；若只想補救 Durant 類 SF 的 help 係數偏低，這個實驗沒有支持的做法。
2. A3（分位置係數 ridge 收縮）依凍結規則「過門檻」，但區間碰 0、且不是防守來源：建議**先不上線**，先做一個小拆解實驗（A3 只收縮 help 交互 vs 只收縮其餘四種）確認增益來源，再決定要不要進下一版卡；你若想直接採用 A3，卡片重建與版本號由你下令。
3. DEF 顯示欄加 rebound／身高：建議不做。
